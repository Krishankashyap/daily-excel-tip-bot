## VLOOKUP - ID se naam nikalo

```
=VLOOKUP(A2, $D$2:$F$100, 2, FALSE)
```

Employee ID daalo, naam apne aap aa jayega. FALSE ka matlab exact ID milni chahiye, warna galat naam aa sakta hai.
